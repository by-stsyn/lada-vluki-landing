# Управление изображениями на лендинге Geely

## Структура изображений

Все изображения находятся в папке `public/`. Эта папка доступна напрямую через URL сайта.

## Изображения моделей автомобилей

### Расположение файлов

Изображения моделей хранятся в следующих папках:

```
public/
├── monjaro/           # Фотографии Geely Monjaro
│   ├── monjaro-1.png
│   ├── monjaro-2.png
│   ├── monjaro-3.png
│   └── monjaro-4.png
└── geely.png          # Изображение по умолчанию для остальных моделей
```

### Как добавить/изменить фотографии модели

#### Вариант 1: Использовать существующее универсальное изображение

Сейчас для большинства моделей используется файл `/geely.png`. Вы можете просто заменить этот файл на нужное изображение.

#### Вариант 2: Создать отдельную папку для модели (рекомендуется)

1. Создайте папку в `public/` с названием модели (например, `public/atlas/`)
2. Добавьте в неё 4 изображения:
   - `atlas-1.png` (или .jpg)
   - `atlas-2.png`
   - `atlas-3.png`
   - `atlas-4.png`

3. Откройте файл `src/App.tsx`
4. Найдите нужную модель в массиве `cars` (примерно строка 33-151)
5. Измените массив `images`:

```typescript
{
  id: 'atlas',
  name: 'ATLAS',
  badge: 'НОВИНКА',
  price: 'от 2 799 000 ₽',
  images: [
    '/atlas/atlas-1.png',  // Было: '/geely.png'
    '/atlas/atlas-2.png',  // Было: '/geely.png'
    '/atlas/atlas-3.png',  // Было: '/geely.png'
    '/atlas/atlas-4.png',  // Было: '/geely.png'
  ],
  // ... остальные поля
}
```

### Требования к изображениям

- **Формат**: PNG или JPG
- **Размер**: Рекомендуется 1200x800 пикселей или больше
- **Соотношение сторон**: 3:2 (горизонтальная ориентация)
- **Вес файла**: До 500 КБ (оптимизируйте изображения перед загрузкой)

## Изображение главного баннера

### Текущее изображение

Главный баннер использует файл `/geely.png` с эффектом наложения (overlay).

### Как изменить изображение главного баннера

1. Подготовьте новое изображение:
   - **Размер**: минимум 1920x1080 пикселей
   - **Формат**: JPG или PNG
   - **Соотношение**: 16:9 или шире

2. Замените файл `public/geely.png` на ваше изображение

   ИЛИ

   Добавьте новый файл (например, `public/hero-banner.jpg`) и измените код:

3. Откройте файл `src/App.tsx`
4. Найдите секцию с `id="hero"` (примерно строка 244)
5. Измените путь к изображению:

```typescript
<img src="/hero-banner.jpg" alt="" className="w-full h-full object-cover mix-blend-overlay" />
```

## Логотип Geely

`public/logo-brand.svg`

### Как заменить

Просто замените файл `public/logo-brand.svg` на новый логотип в формате SVG.

## Процесс обновления изображений

### Шаг 1: Подготовка файлов

1. Оптимизируйте изображения (можно использовать tinypng.com или другие сервисы)
2. Переименуйте файлы согласно структуре выше
3. Убедитесь, что форматы правильные (PNG/JPG для фото, SVG для логотипов)

### Шаг 2: Загрузка на сервер

1. Откройте папку `public/` в вашем проекте
2. Создайте нужные подпапки (если требуется)
3. Скопируйте изображения в соответствующие папки
4. Если нужно, обновите пути в файле `src/App.tsx`

### Шаг 3: Проверка

1. Запустите проект локально: `npm run dev`
2. Проверьте, что все изображения отображаются корректно
3. Проверьте на разных размерах экрана (десктоп, планшет, мобильный)

### Шаг 4: Деплой

1. Соберите проект: `npm run build`
2. Задеплойте изменения на сервер

## Рекомендации

### Оптимизация изображений

- Используйте WebP формат для лучшего сжатия (поддержка современными браузерами)
- Не загружайте изображения больше 1 МБ
- Используйте онлайн-инструменты для сжатия без потери качества

### Именование файлов

- Используйте латинские символы без пробелов
- Используйте дефисы вместо подчёркиваний: `atlas-1.png` вместо `atlas_1.png`
- Используйте понятные имена: `monjaro-front.png` лучше чем `img001.png`

### Резервное копирование

Перед заменой изображений сделайте резервную копию старых файлов на случай, если понадобится вернуть изменения.

## Поддержка

Если у вас возникли проблемы с отображением изображений:

1. Проверьте правильность путей в коде
2. Убедитесь, что файлы загружены в папку `public/`
3. Проверьте консоль браузера на ошибки загрузки (F12 → Console)
4. Убедитесь, что имена файлов совпадают с указанными в коде (включая регистр)
